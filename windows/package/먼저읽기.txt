아나 for Windows

설치 / 업데이트
1. 압축을 모두 풉니다.
2. 설치.cmd를 실행합니다. 이전 버전이 실행 중이면 트레이에서 종료한 뒤 실행하세요.
3. 바탕 화면의 아나를 실행합니다.

처음 한 번만 설치하면 됩니다.
- 6시간마다 아나 서버에서 새 버전을 확인합니다.
- 새 버전이 있으면 트레이 알림이 뜹니다. 알림을 누르면 내려받아 확인(SHA-256)한 뒤 자동으로 교체하고 다시 시작합니다.
- 트레이 메뉴의 [업데이트 확인]으로 바로 확인할 수도 있습니다.
- 설정, 연결한 기기, 받은 파일, 서버 연결 키는 %LOCALAPPDATA%\Ahna에 있어 업데이트해도 그대로입니다.

처음 실행하면 옵션 창이 열립니다. 받은 초대 코드를 넣고 [가입]을 누르세요.

제거: 제거.cmd (받은 파일과 설정은 남습니다)
