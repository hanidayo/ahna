아나 for Windows

설치
1. 압축을 모두 풉니다.
2. 설치.cmd를 실행합니다. 아나가 이미 실행 중이면 트레이에서 종료한 뒤 실행하세요.
3. 바탕 화면의 "아나 Open"을 실행합니다.

처음 실행하면 옵션 창이 열립니다. 서버를 만든 사람에게 받은 서버 주소와 초대 코드를 넣고 [연결]을 누르세요.
"Windows 보안 경고(방화벽)"가 뜨면 [액세스 허용]을 누르세요(같은 Wi-Fi 기기끼리 바로 보낼 때 필요).

업데이트
- 6시간마다 새 버전을 확인하고, 있으면 트레이 알림이 뜹니다. 알림을 누르면 내려받아 확인(SHA-256)한 뒤 자동으로 바꾸고 다시 시작합니다.
- 트레이 메뉴의 [업데이트 확인]으로 바로 확인할 수도 있습니다.
- 설정, 연결한 기기, 서버 연결 정보는 %LOCALAPPDATA%\AhnaOpen에 있어 업데이트해도 그대로입니다.

제거: 제거.cmd (받은 파일과 설정은 남습니다)
