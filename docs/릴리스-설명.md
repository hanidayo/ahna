## 아나 {VERSION}

Windows · Mac · iPhone/iPad · Android 사이에서 파일과 글자를 주고받는 앱입니다. 직접 운영하는 서버에 연결해서 씁니다.

### 내려받기

| 기기 | 파일 |
|---|---|
| Windows 10·11 | [Ahna-Setup.exe](https://github.com/{REPO}/releases/download/v{VERSION}/Ahna-Setup.exe) |
| Mac (macOS 13 이상) | [Ahna-Mac.zip](https://github.com/{REPO}/releases/download/v{VERSION}/Ahna-Mac.zip) |
| iPhone · iPad (iOS 17 이상) | [Ahna-iOS.ipa](https://github.com/{REPO}/releases/download/v{VERSION}/Ahna-iOS.ipa) — Sideloadly · AltStore · Feather 등으로 서명해 설치 |
| Android 10 이상 | [Ahna-Android.apk](https://github.com/{REPO}/releases/download/v{VERSION}/Ahna-Android.apk) |
| 서버 (Docker) | [Ahna-Server.zip](https://github.com/{REPO}/releases/download/v{VERSION}/Ahna-Server.zip) |

### 처음 쓸 때

1. 서버가 없다면 먼저 만드세요: [우분투](https://github.com/{REPO}/blob/main/docs/서버-우분투.md) · [시놀로지 NAS](https://github.com/{REPO}/blob/main/docs/서버-시놀로지.md)
2. 앱을 설치하고 처음 열면 나오는 화면에 **서버 주소**와 **초대 코드**를 넣으세요: [앱 설치 안내](https://github.com/{REPO}/blob/main/docs/앱-설치.md)

---

**English** — Ahna {VERSION}: send files and clipboard text between Windows, Mac, iPhone/iPad and Android through your own server. Install the app for your device above and enter your server address and invite code on first launch. To run a server, see the docs folder.
