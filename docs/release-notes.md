## 아나 {VERSION}

> 경상도 말로 "아나~" — 옛다, 받아라. 툭 건네듯 주고받는 앱입니다.

| 기기 | 파일 | 설치 |
|---|---|---|
| Windows | [Ahna-Setup.exe](https://github.com/hanidayo/ahna-releases/releases/download/v{VERSION}/Ahna-Setup.exe) | 내려받아 실행하면 설치됩니다. ‘Windows의 PC 보호’ 창이 뜨면 [추가 정보] → [실행] |
| Mac | [Ahna-Mac.zip](https://github.com/hanidayo/ahna-releases/releases/download/v{VERSION}/Ahna-Mac.zip) | 압축을 풀고 아나를 응용 프로그램 폴더로 옮기세요. ‘확인되지 않은 개발자’ 경고가 뜨면 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 [그래도 열기] |

## Ahna {VERSION} (English)

Ahna ("here, catch!" in the Gyeongsang dialect of Korean) sends files and clipboard text between Windows, Mac, iPhone/iPad and Android.

- **Windows** — run `Ahna-Setup.exe`. If SmartScreen appears, choose *More info* → *Run anyway*.
- **Mac** — unzip `Ahna-Mac.zip` and move Ahna to Applications. If macOS blocks it, use *Open Anyway* in System Settings › Privacy & Security.
- **Android** — install `Ahna-Android.apk` (allow installs from unknown sources).
- **iPhone / iPad** — `Ahna-iOS.ipa`, install with a sideloading tool such as Sideloadly.

On first launch the app asks for an invite code — get it from the person who shared Ahna with you. After that the apps notify you about updates.
