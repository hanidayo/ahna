# 아나 앱 설치하고 쓰기

설치 파일은 이 저장소의 **Releases**(최신 버전)에 있습니다.

| 기기 | 받을 파일 |
|---|---|
| Windows 10·11 (64비트) | `Ahna-Setup.exe` (또는 압축판 `Ahna-Windows.zip`) |
| Mac (macOS 13 이상, Apple 실리콘·인텔) | `Ahna-Mac.zip` |
| iPhone · iPad (iOS 17 이상) | `Ahna-iOS.ipa` |
| Android 10 이상 | `Ahna-Android.apk` |

처음 열면 모든 앱이 **서버 주소**와 **초대 코드**를 묻습니다. 서버를 만든 사람에게 받으세요.
서버 주소는 `https://ahna.example.com` 같은 꼴이고, 서버의 내려받기 화면(`서버주소/download`)에도 적혀 있습니다.

---

## Windows

1. `Ahna-Setup.exe`를 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**을 누르세요(서명하지 않은 앱이라 뜹니다).
2. 설치가 끝나면 아나가 열리고 옵션 창이 뜹니다. **서버 주소**와 **초대 코드**를 넣고 **[연결]**
3. **"Windows 보안 경고(방화벽)"**가 뜨면 **[액세스 허용]**을 누르세요. 같은 Wi-Fi의 내 기기가 서버를 거치지 않고 바로 보낼 때 필요합니다.

- 아나는 작업 표시줄 오른쪽 아래(트레이)에 있습니다. 아이콘을 누르면 화면이 열립니다.
- 탐색기에서 파일을 오른쪽 클릭 › **아나로 보내기**로 바로 보낼 수 있습니다(옵션에서 켜고 끔).
- 설치 위치: `%LOCALAPPDATA%\Programs\AhnaOpen`, 설정·기록: `%LOCALAPPDATA%\AhnaOpen`
- 제거: 설정 › 앱 › 설치된 앱 › 아나(받은 파일은 남습니다)

## Mac

1. `Ahna-Mac.zip`을 풀면 나오는 앱을 **응용 프로그램** 폴더로 옮깁니다(Finder에는 "아나"로 보입니다).
2. 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면 **시스템 설정 › 개인정보 보호 및 보안** 맨 아래의 **[그래도 열기]**를 누르세요.
3. 첫 화면에 **서버 주소**와 **초대 코드**를 넣고 **[시작하기]**
4. "들어오는 네트워크 연결을 허용하시겠습니까?"가 뜨면 **허용**(같은 Wi-Fi 바로 보내기용)

- 아나는 메뉴 막대(화면 위 오른쪽)에 있습니다.
- Finder나 다른 앱의 **공유 메뉴 › 아나**로 바로 보낼 수 있습니다. 공유 메뉴에 없으면 시스템 설정 › 일반 › 로그인 항목 및 확장 프로그램 › 공유에서 켜세요.
- 새 버전이 나오면 앱이 알려 주고, 누르면 알아서 바꿔 설치합니다.

## iPhone · iPad

iPhone 앱은 App Store가 아니라 직접 설치하는 방식이라 **설치 도구로 서명**해야 합니다. 셋 중 편한 것을 쓰세요.

| 도구 | 필요한 것 | 비고 |
|---|---|---|
| [Sideloadly](https://sideloadly.io) | Windows·Mac + 무료 Apple ID | 무료 Apple ID는 7일마다 다시 서명해야 합니다(자동 갱신 기능 있음) |
| [AltStore](https://altstore.io) / [SideStore](https://sidestore.io) | 무료 Apple ID | 7일 갱신을 휴대폰에서 할 수 있습니다 |
| Feather 등 | 개발자 인증서(.p12)와 프로비저닝 프로파일 | 유료 개발자 계정이나 인증서가 있으면 갱신 걱정이 없습니다 |

설치할 때 **공유 확장(AhnaShare)을 빼지 마세요.** 공유 메뉴로 보내기에 필요합니다.

1. 설치한 아나를 열고 **서버 주소**와 **초대 코드**를 넣은 뒤 **[시작하기]**
2. "로컬 네트워크의 기기를 찾고 연결"을 묻으면 **허용**(같은 Wi-Fi 바로 보내기용)
3. Bluetooth 사용을 물으면 **허용**(근처 기기용)

- 사진 앱·파일 앱 등의 **공유 버튼 › 아나**로 바로 보낼 수 있습니다.
- 아이폰은 **아나가 화면에 열려 있을 때만 받습니다.** 받을 때는 아나를 열어 두세요.
- 받은 사진·동영상은 사진 앱에, 다른 파일은 파일 앱 › 나의 iPhone › 아나에 저장됩니다(옵션에서 바꿀 수 있음).

## Android

1. `Ahna-Android.apk`를 휴대폰에서 받아 엽니다.
2. "출처를 알 수 없는 앱" 설치를 물으면 **설정에서 허용**한 뒤 설치합니다.
3. 처음 열면 뜨는 창에 **서버 주소**와 **초대 코드**를 넣고 **[연결]**
4. 근처 기기·알림 권한을 물으면 **허용**

- 다른 앱의 **공유 › 아나**로 바로 보낼 수 있습니다.
- 받은 사진·동영상은 갤러리(사진/동영상 › Ahna)에, 다른 파일은 다운로드 › Ahna에 저장됩니다.

## 처음 쓸 때: 내 기기끼리 연결하기

서버에 가입한 기기끼리 한 번 **연결**해 두면, 그다음부터는 목록에서 골라 바로 보냅니다.

1. 받을 기기에서 **이 기기의 연결 코드**(6자리)를 확인합니다. 휴대폰은 옵션 맨 위, Windows·Mac은 첫 화면에 있습니다.
2. 보낼 기기에서 **기기 추가**를 누르고 그 코드를 넣습니다.
3. 한 번만 하면 양쪽 모두에 서로가 추가됩니다.

## 주고받기

| 하고 싶은 것 | 방법 |
|---|---|
| 파일 보내기 | 보낼 기기를 고르고 [파일 보내기], 또는 탐색기·Finder·공유 메뉴에서 **아나** |
| 글자(클립보드) 보내기 | 글자 칸에 붙여 넣고 [글자 보내기] |
| 옆에 있는 사람에게 (연결 안 한 기기) | **근처 기기**: 상대도 아나를 열고 "근처 기기에서 받기"를 켜 두면 목록에 뜹니다. 양쪽 화면의 확인 숫자가 같으면 보내세요 |
| 아나가 없는 사람에게 | **QR로 보내기**: 상대가 휴대폰 카메라로 QR을 찍으면 브라우저에서 파일이나 글자를 받습니다. 반대로 **QR로 받기**를 열면 상대가 브라우저로 파일을 보낼 수 있습니다 |

- 같은 Wi-Fi에 있으면 서버를 거치지 않고 기기끼리 바로 보냅니다(자동). 다른 곳에 있으면 서버를 거칩니다.
- 큰 파일도 됩니다(한 파일 최대 4GB).
- 서버 관리자가 공지를 보내면 앱 위쪽 종 아이콘에 뜹니다.

## 업데이트

새 버전이 나오면 앱이 알려 줍니다.
- Windows·Mac: 알림을 누르면 내려받아 확인한 뒤 자동으로 바꿔 설치합니다.
- iPhone: 새 IPA를 같은 설치 도구로 다시 설치하면 됩니다(설정·연결은 유지).
- Android: 알림의 [내려받기]로 새 APK를 받아 설치하면 됩니다(설정·연결은 유지).

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "서버 주소가 올바르지 않습니다" | `https://`로 시작하고 끝에 `/`나 경로가 없는 주소인지 (예: `https://ahna.example.com`) |
| "초대 코드를 너무 많이 시도했습니다" | 10분 뒤 다시 시도하세요 |
| 연결됐다가 "다시 연결" 화면이 뜸 | 서버 관리자가 이 기기를 초기화했거나 차단했습니다. 관리자에게 문의하세요 |
| 같은 Wi-Fi인데 느림 | Windows 방화벽 허용, 아이폰 로컬 네트워크 권한(설정 › 아나), 공유기의 "AP 격리(손님 Wi-Fi)" 기능이 꺼져 있는지 |
| 아이폰으로 보낸 게 안 감 | 받는 아이폰에서 아나가 화면에 열려 있어야 합니다 |
