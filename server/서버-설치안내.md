# 아나 서버 설치 (Synology Container Manager)

1. NAS에 폴더를 만듭니다. 예: `/volume1/docker/ahna`
2. 이 압축 파일의 `compose.yaml`을 그 폴더에 넣고, `.env.example`을 복사해 이름을 **`.env`** 로 바꿉니다(앞의 점 포함).
3. `.env`를 채웁니다.
   - `AHNA_ORIGIN` : 서버 주소 (예: `https://example.synology.me`)
   - `AHNA_KEY` : 64자리 이상의 임의의 16진수
   - `AHNA_INVITE` : 지인에게 알려 줄 초대 코드 (6자 이상)
   - `AHNA_PUBLISH_KEY` : 앱 업데이트를 올리는 키 (GitHub 저장소 비밀값과 같은 값)
4. Container Manager › 프로젝트 › 생성 → 경로에 위 폴더, `compose.yaml` 사용 → 빌드
5. 제어판 › 로그인 포털 › 고급 › 역방향 프록시: `https://(서버 주소):443` → `http://localhost:45833`, 사용자 지정 머리글에 WebSocket 추가

- 서버 프로그램은 watchtower가 매일 04:30 자동으로 새 이미지로 바꿉니다.
- 앱 업데이트 파일은 GitHub Actions가 서버로 직접 올리므로 컨테이너를 다시 만들 필요가 없습니다.
- 내려받기 화면: `https://(서버 주소)/_ahna/download`
